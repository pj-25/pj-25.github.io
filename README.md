# pj-25 site

Portfolio and project hub. Static Astro site; content lives in `src/data/*.json` and `src/pages/**/*.md`.
```sh
npm install && npm run dev     # local
npm run build                  # → dist/ (static, no client JS)
```
Every claim must trace to a repository, commit history or an approved description. The source of truth is `agentic-os/initiatives/engineering-identity/`.
